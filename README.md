# frontend-ignited
This is for learning HTML, CSS, JS and React

1.	HTML5 – structure of web pages
2.	CSS3 – styling and layouts
3.	JavaScript (ES6+) – interactivity and logic
4.	React.js – build UI components
5.	Next.js – server-side rendering & routing
6.	Redux Toolkit – state management
7.	Tailwind CSS / MUI – modern styling frameworks
8.	Git & GitHub – version control
9.	npm / yarn – package management
10.	Figma – UI/UX design & prototyping
